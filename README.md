# Tailbridge SST template

This public template deploys Tailbridge with SST. It imports the published Tailbridge component package.

Do not fork the Tailbridge source repository for a deployment. Create a repository from this template instead.

The deployment creates one shared DigitalOcean edge. It creates one Railway connector for each configured project.

See [docs/setup.md](docs/setup.md) for the deployment procedure, update process, rollback procedure, and recovery steps.
